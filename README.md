La funzione verifica se un grafo orientato soddisfa tre proprietà:
1 - Il numero totale di archi deve essere pari.
2 - Non devono essere presenti auto-archi, cioè archi che collegano un nodo a sé stesso.
3 - Per ogni nodo, il grado uscente deve essere strettamente minore del numero di nodi che hanno al massimo un arco entrante.
